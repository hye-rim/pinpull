# 핀 뽑기 퍼즐 📌

핀을 뽑는 순서를 정해 영웅이 용암·바위를 피해 보물까지 떨어지게 하는 퍼즐입니다(12단계). 서버 없이 `index.html` 만 열면 돌아갑니다.

- 조작: 회색 **핀을 눌러 뽑기**. 모든 것이 멈춘 뒤에만 다음 핀을 뽑을 수 있습니다. **↶ 되돌리기**(`Z`)는 마지막 핀을, **↺ 처음부터**(`R`)는 단계를 다시, **💡 힌트**는 이기는 길이 이어지는 핀을 반짝이게 합니다. `M` 소리.
- 규칙: 영웅은 떨어지기만 하고, 보물 **바로 옆**(상하좌우)에 닿으면 성공. 🔥 용암에 닿거나(떨어지는 용암에 맞기·옆에 붙기) 🪨 바위에 깔리면 실패. 용암은 아래가 막히면 비스듬히 흘러내립니다. ⭐ 은 영웅이 닿으면 모아집니다.
- 별: ⭐ 한 개 = 성공, ⭐⭐ = 모든 별을 모음, ⭐⭐⭐ = 별을 다 모으며 기준(par) 핀 수로 성공.
- **같은 순서면 항상 같은 결과**가 나오는 칸 단위 물리라서, 풀이 계산(`solve`)으로 모든 단계가 풀리고 모든 별을 모을 수 있음을 확인합니다. 힌트도 이 계산을 씁니다.
- 12단계는 손으로 만든 3개(1~3단계)와 무작위로 만든 뒤 풀이 계산으로 걸러 낸 9개(층 수와 핀 수가 늘어남)입니다. 걸러 낸 기준: 풀 수 있음, 모든 별을 모을 수 있음, 핀을 아무렇게나 뽑았을 때 이길 확률이 8~55%, 핀 수 6개 이하.
- 기록: 단계별 별은 `pinpullStars`, 별 합계는 `pinpullBest`. 앞 단계를 깨면 다음 단계가 열립니다.
- `logic.js` 규칙·풀이(`LOGIC_PIN`), `game.js` 화면·입력·소리, `test/logic.test.js` (`node --test`).
